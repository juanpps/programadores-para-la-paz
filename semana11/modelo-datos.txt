Entidad: Causa

Campos principales:
- id
- titulo
- descripcion
- fecha

Propósito:
Guardar las causas comunitarias que serán visibles en la plataforma, permitiendo que cualquier ciudadano conozca las iniciativas activas.


Entidad: Apoyo

Campos principales:
- id
- causa_id
- usuario
- fecha

Propósito:
Registrar los apoyos que recibe cada causa para hacer seguimiento a la participación ciudadana y medir el nivel de respaldo comunitario.


Entidad: Usuario

Campos principales:
- id
- nombre_usuario
- correo
- password_hash
- fecha_registro

Propósito:
Identificar a las personas que interactúan con la plataforma, controlar el acceso a funciones como crear causas o apoyar, y mantener trazabilidad de quién realiza cada acción sin exponer datos sensibles.
