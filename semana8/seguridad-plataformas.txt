1. No exponer datos personales de los usuarios en respuestas de la API ni en repositorios públicos.
2. Proteger credenciales (contraseñas, tokens, claves API) usando variables de entorno y nunca subirlas a Git.
3. Usar conexiones seguras (HTTPS) para proteger la información que viaja entre el cliente y el servidor.
4. Registrar accesos y acciones importantes para poder detectar actividad sospechosa.
5. Limitar el acceso a información sensible mediante roles y permisos, asegurando que cada usuario solo vea lo que le corresponde.
